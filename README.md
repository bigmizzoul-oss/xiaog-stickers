# 小G公主表情包 🐉💜

24 张表情包，静态图床版本。

## 部署

1. 创建 **Public** GitHub 仓库，推荐 `xiaog-stickers`。
2. 将本 ZIP 的 **内部文件** 上传到仓库默认分支的根目录。
3. GitHub 仓库 → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save。
4. 网站通常为 `https://用户名.github.io/xiaog-stickers/`。
5. 图片链接如 `https://用户名.github.io/xiaog-stickers/images/sticker-12.png`。

`stickers.json` 是编号和中文表情名称对应的索引；新增表情时附加图片并更新 JSON 即可。

注意：仓库与 Pages 内容均为公开；不要上传聊天记录或私人信息。
